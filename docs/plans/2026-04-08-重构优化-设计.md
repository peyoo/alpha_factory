# 重构优化设计文档

**日期**: 2026-04-08
**范围**: 代码结构整理——拆分过大文件、提取重复代码为公共函数，不动公共接口
**目标**: 提升可维护性，消除重复逻辑，保持全部 158 个测试通过

---

## 1. 背景与动机

当前代码库约 24K 行，功能完整，ruff/pytest 全部通过。但存在以下结构问题：

| 问题 | 影响文件 |
|---|---|
| 单文件代码过多 | `cli/trades.py`（1321行）混合 CLI/ML/SHAP/HTML 多种职责 |
| 数据层文件臃肿 | `data_provider/unified_factor_builder.py`（600行） |
| DataProvider 初始化重复 | `eval.py`、`evals.py`、`opt.py`、`opt2.py`、`trades.py` 各自独立初始化 |
| pool 解析逻辑重复 | `_resolve_pool` / `_get_pool_universe` 在 4 处有几乎一致的实现 |

---

## 2. 设计方案（Phase 1 + Phase 2）

### Phase 1：提取 cli 共享工具

#### 新文件：`src/alpha_factory/cli/_loader.py`

**职责**：统一 PoolUniverse 解析 + DataProvider 加载入口

```
导出函数：
  resolve_pool(pool_name: str) -> PoolUniverse
    - 遍历 PoolUniverseEnum，按 name 匹配，找不到时 raise ValueError
    - 替代：opt.py._resolve_pool、opt2.py._resolve_pool、
             eval_core.py._get_pool_universe、trades.py._resolve_pool

  load_pool_lf(
      pool: PoolUniverse,
      exprs: list[str],
      start_date: str,
      end_date: str | None,
      actions: list | None = None,
  ) -> pl.LazyFrame
    - 封装 DataProvider() 初始化 + load_pool_data(...)
```

**修改文件**：
- `cli/eval_core.py`：删除 `_get_pool_universe`、`_load_data`，改用 `_loader`
- `cli/opt.py`：删除 `_resolve_pool`，改用 `_loader.resolve_pool`
- `cli/opt2.py`：删除 `_resolve_pool`，改用 `_loader.resolve_pool`
- `cli/trades.py`：删除 `_resolve_pool`，改用 `_loader.resolve_pool`

### Phase 2：拆分超大文件

#### 2a. `cli/trades.py` 拆分为 3 个文件

| 文件 | 内容 | 估算行数 |
|---|---|---|
| `cli/trades.py` | CLI 参数定义、主流程 `quant_trades`、`_parse_feature_exprs`、`_attach_buy_features`、`_run_filter_analysis`、`_run_rank_analysis`、`_prepare_xy`、`_compute_shap`、`_save_df`、`_print_analysis_summary` | ~350 行 |
| `cli/_trades_viz.py` | `_configure_mpl`、`_shap_to_base64`、`_detect_shap_threshold`、`_shap_dependence_grid`、`_shap_heatmap_by_time`、`_shap_interaction_plots`、`_shap_decision_plots` | ~350 行 |
| `cli/_trades_html.py` | `_build_diagnosis_html`、`_generate_html_report` | ~350 行 |

`trades.py` 通过 `from alpha_factory.cli._trades_viz import ...` 和 `from alpha_factory.cli._trades_html import ...` 引用，对外接口不变。

#### 2b. `data_provider/unified_factor_builder.py` 拆分

| 文件 | 内容 | 估算行数 |
|---|---|---|
| `unified_factor_builder.py` | `UnifiedFactorBuilder` 类入口、`build_unified_factors`、`datas`、`_execute_single_year_build`、`_load_prev_year_anchor`、`_generate_skeleton_lf`、`_ensure_valid_assets`、`_validate_unified_factors` | ~280 行 |
| `_data_cleaner.py` | `DataCleanerMixin`：7 个 `_op_clean_*` 方法 + `_op_process_indicators` | ~320 行 |

`UnifiedFactorBuilder` 继承 `DataCleanerMixin`，对外接口不变。
